API reference

Base URL:   {{ base_url }}/api/v1/
Auth:       Authorization: Bearer <your_token>

GET    /api/v1/products              List products (filter: ?scope=in&compliant=true)
GET    /api/v1/products/{id}         Get single product
PATCH  /api/v1/products/{id}         Update classification: {is_in_scope, commodity, hs_code, plot_ids}

GET    /api/v1/plots                 List plots (filter: ?country=BR)
POST   /api/v1/plots                 Create plot: {name, country, plot_type, coordinates, area_hectares, ...}

GET    /api/v1/dds                   List DDS (filter: ?status=submitted)
POST   /api/v1/dds                   Create DDS: {eudr_product_id, consignment_quantity, country_of_production, plot_ids, risk_level, eu_reference_number, ...}
GET    /api/v1/dds/{id}              Get single DDS

POST   /api/v1/widget/publish        Publish EUDR metafields to all in-scope products
